# Users

## When to Use
- User asks about WordPress user roles and what each role can do
- User wants to manage users (create, edit, delete, change role)
- User asks about user capabilities or permissions

## Available Tools
- No direct user management tools exist in Wally

## Workflows

### Explain WordPress User Roles
When the user asks about roles, explain the built-in roles:
- **Administrator** — full site access: manage settings, plugins, themes, all users
- **Editor** — manage all content (own and others'), moderate comments, manage categories
- **Author** — create and publish own posts, upload media
- **Contributor** — write posts but cannot publish (requires Editor/Admin approval)
- **Subscriber** — read-only access, manage own profile only

### Direct User Management to Admin
For ALL user management tasks, guide the user to WordPress admin:
- Create user → Users > Add New
- Edit user / change role → Users > All Users > click user name
- Delete user → Users > All Users > hover over user > Delete
- Reset password → Users > All Users > click user > New Password section

## Important Notes
- Wally has no tools to create, list, edit, or delete users
- Wally has no tools to change user roles or capabilities
- For all user management, direct the user to the **Users** section in WordPress admin
- Plugin-specific roles (e.g., WooCommerce Customer, Shop Manager) must also be managed via admin
